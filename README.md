# AI 工作站搭建记录

这是一个进行中的项目：用 AI（DeepSeek Harness）+ Obsidian，从零搭一套自己能跑的个人工作流。

记录的重点不是"装了什么"，而是**每个决定为什么这么定、踩了什么坑、失败之后怎么改**。

## 起点

- 2026 年 11 月开始，零命令行基础
- 每天投入约 1 小时
- 目标：半年内搭出能用的系统，同时作为转 AI 相关岗位的作品

## 现在的样子

```
工作区 D:\知识库
├── AGENTS.md            # 给 AI 的行为契约
├── .dsh/skills/         # 我自己写的 AI 技能
└── 随心的知识库/         # 知识库本体（不公开）
    ├── 00-收件箱/
    ├── 10-学习/{课程,读书,卡片}/
    ├── 20-主题/          # 主题地图
    ├── 30-内容/{选题,稿件,已发布}/
    ├── 40-项目/
    ├── 50-日志/每日/
    ├── 90-归档/
    ├── _模板/
    └── _附件/
```

## 核心设计

**1. 笔记只分四类**
来源（书/课）、卡片（一个观点一张）、主题地图、输出。用 frontmatter 的 `type` 区分，不用文件夹。

**2. AI 的行为写在 `AGENTS.md` 里**
不是每次都重新解释背景，而是让 AI 每次开工前自动读一份契约。

**3. 三个技能固化三条流水线**
收件箱分拣 → 来源拆卡 → 卡片成稿。

**4. 不要空壳**
一张卡不建地图，一个概念不建目录。等有三张同类卡再建。

## 踩过的坑

| 坑 | 怎么发现的 | 怎么改的 |
|---|---|---|
| Windows 文件权限挡住 AI 写文件 | DSH 报 workspace grant 失败 | 定位到缺 WRITE_OWNER，补权限后复验 |
| `AGENTS.md` 放错层级 | AI 去库根目录找 `00-收件箱`，找不到 | 工作区设成库的上一层，并在契约里写明路径基准 |
| 一次装 8 个 Obsidian 插件 | 还没用上就先被配置拖死 | 改成装文件、按周启用 |
| 让 AI 全权整理 | 库会变成 AI 的样子 | 改成 AI 只出候选，人做决定 |
